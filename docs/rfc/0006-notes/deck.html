The honest problem

Great engine, buried in a machine shop

Over two years this app grew a “curriculum factory” and fancy plumbing nobody asked for. Like a house where you have to walk through a workshop to reach the kitchen.

What's in the way

  • A fresh install shows zero topics. The topic list lives only in a database file that isn't part of the app — so on a new laptop, she literally can't practice the bug this plan fixes
  • Her practice screen is crowded code — a 1,000-line page doing sign-in, search, practice, tests and suggestions all at once
  • Duplicated machinery — two question-picking systems, three databases, ~20 settings knobs
  • Five dead doors — buttons and pages no screen links to anymore

Why this hurts her scores

  • Setup friction = fewer practice days (and consistency is everything)
  • Crowded screen = distraction tax on every single question
  • Complexity = every improvement takes longer and risks breaking practice
The fix is subtraction: keep the tested engine, remove the factory. About a third of the code goes away — none of it code she uses.

Milestone 5 · safety net

Her progress lives in one safe file — and you hold the key

Already solid today verified

  • All her history is stored in one industry-standard database (SQLite — the one inside every phone and browser)
  • Sign-ins are protected the way banks do it: salted, slow-hashed passwords; lockout after failed tries; sessions that expire
  • Every write is checked against tampering from outside the app
  • Answers and history are stored safely — never shown raw to anyone but her

What we're adding new

  • One-tap backup from the admin screen — a single file you can copy to a USB stick or cloud drive
  • Export her progress as a readable file (and reset if ever needed)
  • A health panel — green lights for database, topics, everything (so you know it's OK without asking anyone)
  • A first-run admin account — today there's literally no way to create an admin on a fresh install; we fix that
Bottom line: her years of practice history become a single portable file you can back up in one tap. Local-first — no cloud account needed, nothing leaves the house.

What could go wrong — and the one call I need from you

Risks, handled

Risk How we protect her
Screen changes break practice Every change lands with all tests green; each milestone is its own reversible checkpoint
Topic list migration New catalog ships inside the app, reviewed like a textbook — installed before the old pipeline is removed
Data merge hiccup Her accounts and history are copied forward, never transformed in place; old file kept

one decision A display library

Today the app uses an elaborate “remote control” system (A2UI) to draw question buttons and choices — about 1,700 lines to do what one simple component can. I recommend replacing it with the simple one (same safety checks, far less to break). Say yes and milestone 4 proceeds; say keep and we skip it — the plan works either way.
