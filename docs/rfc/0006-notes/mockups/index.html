Odyssey — future state

Three personas · one simple local application. Static mockups accompanying docs/rfc/0006-simplify-to-persona-app.md.

Persona 1

Student — practice app

Sign-in, pick a skill, one question at a time with diagrams, hints and solution steps. Focused: a single task per screen.

Persona 2

Parent — dashboard

Child progress at a glance: streaks, mastery by domain, what to practice next. Manage child accounts.

Persona 3

Admin — console

Accounts (parents & students), the curriculum catalog seeded from the versioned JSON, question-bank coverage, system health.

What these are not: pixel-final designs. They fix layout, information hierarchy, and scope for the three personas so the simplification phases build toward a known target. Design tokens (color, radius, spacing) are shared across all three pages and map to the app’s existing restrained token-based theme.
