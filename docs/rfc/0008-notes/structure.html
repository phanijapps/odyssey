NOW GitHub CI + CODEOWNERS

The single biggest "real project" signal the repo lacks: every push proves itself — lint, typecheck, 210 tests, production build, e2e.

NOW tooling/ + packages/config

tools/ grows up into tooling/; the duplicated tsconfig/eslint settings between web and the engine collapse into one shared base.

GRADUATE packages/core

practice-engine grows into the full pure learning domain — algorithms, curriculum, validators — testable with zero framework deps, exactly where SmartScore lands later.

GRADUATE packages/db

All persistence in one honest home: node:sqlite stays — WAL, foreign keys, append-only migrations, zero ORM forever.

PRODUCT SmartScore (BKT)

Bayesian knowledge tracing behind the existing selection seam — every screen gets smarter without adding a screen. The highest-value item in the reference.

PRODUCT Tutor mode

A bounded TutorAgent at the QuestionGenerator seam: hint escalation, dialogue on wrong answers. Guardrails carry over verbatim.

EARNS ITSELF ui · types · turbo · storybook

Each waits for the feature that needs it. Structure follows product — never the reverse.

Refused, on the record: Prisma/Drizzle (our DB layer is 500 tested lines on a zero-dep native driver — dependencies are forever) · tRPC/Hono transport rewrite (the HTTP surface is the security boundary, proven by review + e2e) · empty scaffolding (no folder without a spec).  ·  Detail: docs/rfc/0008-platform-structure.md
