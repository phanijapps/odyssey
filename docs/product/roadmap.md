# Roadmap

> Direction for the next 2-4 quarters. **Not** commitments. The whole point
> of writing this down is that it can change.

**Last updated:** 2026-08-14

## Now (current quarter)

- **AI question generation.** Live — every question is generated by the local
  Ollama model, scoped to Gold standards, with answers and hints. First
  question loads in ~3s via lazy pool generation.
- **Adaptive difficulty graph.** Live — 6-question batches, wrong → easier,
  correct → harder, no repeats.
- **IXL-style practice page.** Live — subject/grade dropdowns, semantic search
  typeahead, collapsible skill browser, full-width practice area.
- **Knowledge graph.** Live — Engram-backed curriculum entities, prerequisite
  chains, learning-pattern capture on every answer, mastery beliefs.
- **Curriculum dashboard.** Live — browse/search Gold records, run the
  ingestion pipeline, parent progress reporting, knowledge-graph search.

## Next (following 1-2 quarters)

- **Prerequisite-aware practice.** Use the knowledge graph to recommend the
  next skill when a child struggles (associativeGraphCandidates / PageRank).
- **Misconception detection.** Cluster wrong-answer patterns via Engram's
  Louvain community detection; surface "your child confuses X with Y" insights
  to parents.
- **ELA question generation.** Extend prompts beyond numeric answers to
  comprehension, grammar, and vocabulary with text-based answer checking.
- **Gold without LLM.** Replace the Gold formalization step with a
  deterministic parser (regex + section structure) to cut ingestion time in
  half and improve reliability.

## Later

- Multi-child households with parent-managed accounts.
- Exportable progress reports (PDF/CSV).
- Belief consolidation cycles (Engram `consolidate`) to decay stale mastery
  estimates.
- Hybrid retrieval (Engram `fuseRrf`) fusing graph + vector + lexical lanes
  for question selection.

## Not in scope

- Cloud deployment or multi-tenant SaaS — this is a local-first single
  household application (ADR-0001).
- Agent approval authority over curriculum — promotion stays human-gated
  (RFC-0002, Charter principle 2).
- Executable agent output in the browser — SVG/A2UI validation stays strict
  (child-math-practice spec).

## How this file is maintained

- **Owners:** the maintainer.
- **Updates:** roadmap items move between sections via small PRs. Substantive
  additions or deletions go through an RFC.
- **Review cadence:** quarterly.
- **Drift signal:** if items in "Now" haven't moved in two consecutive
  reviews, rewrite the roadmap to match reality.
